A storm has shut down the north coast. Turn mirrors and splitters to restore the signal across five optical charts. Play with the mouse, or use arrow keys and Space.

Open `game/index.html` in Chrome to play offline. The game assets are local, and sound is generated in the browser.

For the make.fun dossier, run `node main.ts` with Node.js 22.18 or later and set `MAKEFUN_OUTPUT_DIR` to an empty directory.

Built for [make.fun](https://make.fun/).
